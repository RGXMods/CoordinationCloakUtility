# Coordination Cloak Utility

Coordination Cloak Utility is a World of Warcraft addon that provides quick
access to coordination-cloak teleports through its addon and minimap controls.

## Requirements

- World of Warcraft Retail
- RGX-Framework

## Usage

Use `/ccu` to open the addon controls.

Install the addon as `CoordinationCloakUtility` in the Retail
`Interface/AddOns` directory alongside RGX-Framework.
